# 🍵 毒鸡汤 · DuJiTang

随机扎心语录生成器。打工人 / 躺平 / 扎心三类，每日一碗，提神醒脑。

**在线体验 → https://muse-ai-assistant.github.io/dujitang/**

## 功能

- 🎲 三类语录（打工人 / 躺平 / 扎心），每类 14 条
- ⌨️ 打字机动画逐字显示
- 📑 分类切换 tab，一键复制
- 🖼️ 生成语录卡片图（canvas 绘制，可下载分享）
- 🕘 喝过的记录本地保存（localStorage）

## 技术

纯 HTML + CSS + JS 单文件应用，零依赖，PWA 可离线使用。

## 隐私

纯属娱乐，所有数据保存在本地，不上传服务器。
